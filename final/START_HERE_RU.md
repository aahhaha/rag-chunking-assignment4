## Перед защитой

Начни с `Defence_Guide_RU.md`. Там есть объяснения терминов, всех восьми таблиц, статистики, ограничений и команд. `Speaking_Script_EN.md` содержит речь к каждому слайду, рассчитанную примерно на десять минут. Проговори её с таймером своими словами.

Главная история: мы разрезали статьи тремя способами, сравнили поиск и ответы на одинаковых 500 вопросах и обнаружили проблему слишком длинных semantic-фрагментов. Overlap улучшил поиск, но его преимущество по точным ответам остаётся неопределённым.

## Быстрая демонстрация

Из корня репозитория, в Python со зависимостями `requirements-analysis.txt`, запусти:

```powershell
python final/reproduce.py
```

Команда пересчитает анализ по сохранённым ответам и создаст таблицы и графики статьи. Генератор заново не запускается. Покажи путь числа: `results_main.csv`, затем `assignment4/analysis.json`, затем `final/generated/main.csv`, затем Table 3 в статье.

Полный запуск `run_experiment.py` использует модели и занимает около часа в прежней среде. Для обычной демонстрации на защите он не нужен.
